物料台账 2.7.0 · Windows x64 程序升级包（不含数据）

2.7.0 新增服务器管理：按服务器查看硬件条码，筛选已有物料或录入新条码。
已安装2.6.0的用户可通过“备份与迁移 → 检查更新”一键升级。

2.6.0 新增GitHub在线更新：已内置发布仓库，启动自动检查，确认后下载、校验、备份并重启。
也可在“备份与迁移”点击“检查更新”；“更新设置”可更改仓库或关闭自动检查。
程序不上传台账。公开发布版不内置个人原始清单，没有data时首次打开为空台账。

2.5.0 新增Excel式表头筛选：型号、类别、位置/使用人、状态支持搜索选项、多选和组合。
点击表头 ▾ 打开菜单，勾选后点“应用”；菜单也支持升序、降序。
已筛选表头带 ●，“清除列筛选”可恢复全部列。
已安装2.4.0：无需解压，在“备份与迁移 → 导入更新包”中直接选择本ZIP，确认后自动重启。
旧于2.4.0：按下文手动迁移一次，之后即可在工具内更新。

2.4.0 新增“备份与迁移 → 导入更新包”。从本版开始，以后选取新版 ZIP 即可
自动校验、备份、更新程序和重启，不再手动搬 data；失败时尝试回退旧版。
升级备份位于程序目录 .updates/ 下，数据库备份位于 data/backups/。
以后只能导入版本号更高、带 update-manifest.json 的新更新包。
请只使用本工具提供的更新包。程序保留原数据目录，不接受包内 data。

本次首次升级：2.3.x 还没有更新入口，请仍按下列步骤手动安装一次。
本版同时包含主表隐藏挂账归属、显示详细描述与备注的布局调整。

2.3.1 修复：网站对账列表增加详细描述与资产使用备注列；双击或点击“查看完整详情”
可查看完整描述、PUID、SN、网站备注及修改前后。长内容支持滚动与复制。

2.3.0 新增：批量搜索、自动识别网卡/GPU等类别、网站Excel清单对账。
对账支持 .xlsx/.csv，旧 .xls 请另存为 .xlsx。必须使用本人名下完整网站清单。
先查看新增、减少、信息更新和未补码待核对明细，再确认同步；同步前自动备份。
完整说明见“网站Excel对账说明.md”。

推荐做法：新目录升级，复制工作机最新数据。
1. 在工作机旧程序中点击“备份”，然后退出旧程序。
2. 将本 ZIP 复制到工作机，完整解压到一个新文件夹。
3. 找到旧版物料台账.exe 旁的整个 data 文件夹，复制到新版物料台账.exe 旁。
   注意必须是工作机最新的 data，不是个人 PC 或早期压缩包里的旧数据。
4. 确认新目录同时有：物料台账.exe、_internal 文件夹、data 文件夹。
5. 双击新版物料台账.exe。旧数据会自动兼容升级，数量和日志保留，升级前自动备份。
6. 核对挂账总数、最近日志和非挂账物品；以后使用新目录程序，并更新快捷方式。

旧程序和旧 data 原样保留，核对完成前不要删除。
复制 data 必须在首次启动新版之前完成。若已经启动新版，可退出后复制，或用
“备份与迁移 → 导入旧版台账”选择工作机旧目录 data/ledger.sqlite3。
导入会整体替换新版台账，不是合并；新版原数据会先自动备份。

本包不包含 data 或初始盘点数据库，不会携带个人 PC 的旧账。
如果直接在没有 data 的目录首次运行，程序打开为空台账；请复制或导入工作机最新数据。
无需安装 Python，无需联网。目标电脑为 Windows 10/11 64 位。
